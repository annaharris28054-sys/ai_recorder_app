# 🎨 AI 智能录音机 - UI 设计与技术选型文档

## 一、 UI 视觉规范体系 (Design System)

为了让前端界面达到极简、现代、高颜值的目标，我们定义以下全局样式规范，请在编写代码时严格遵守：

### 1. 色彩面板 (Color Palette)

* **品牌主色 (Primary)**：`#4C4DDC` (深紫蓝色) —— 用于录音按钮、选中状态、关键图标。
* **主色浅化 (Primary Light)**：`#E8E8FF` —— 用于标签背景色、选中的 Tab 下划线。
* **录音深色背景 (Dark Background)**：`#15162B` (深海蓝) —— 仅用于录音进行时的沉浸式界面。
* **常规背景 (Light Background)**：`#F5F7FA` (极浅灰) —— 用于列表页、设置页的底层背景。
* **卡片背景 (Card Background)**：`#FFFFFF` (纯白) —— 带极浅的阴影。
* **文本颜色 (Typography Colors)**：
* 主要文字 (Primary Text)：`#1A1A1A` (近黑，用于标题、转写正文)
* 次要文字 (Secondary Text)：`#8C8C8C` (中灰，用于时间、辅助说明)


* **功能辅助色 (Semantic Colors)**：
* 录音停止 (Danger/Stop)：`#FF4D4F` (亮红)
* 完成/成功 (Success)：`#00C48C` (翠绿)
* 待办/提示 (Warning/Todo)：`#FF9F43` (亮橙)



### 2. 字体与排版 (Typography)

* **字体家族**：使用系统默认无衬线字体（Android: Roboto, iOS: San Francisco）。
* **字号阶梯**：
* 大标题 (H1)：24sp, Bold (用于大数字、空状态提示)
* 页标题 (H2)：18sp, SemiBold (用于顶部导航栏标题)
* 卡片标题 (H3)：16sp, Medium (用于列表标题)
* 正文 (Body)：14sp, Regular (用于转写文本、总结内容)
* 辅助文本 (Caption)：12sp, Regular (用于时间戳、小标签)



### 3. 布局与间距 (Spacing & Layout)

* **基础网格**：采用 8px 栅格系统。
* **全局边距 (Margin)**：屏幕左右两边距统一为 `16px`。
* **卡片内边距 (Padding)**：卡片内部四周统一留白 `16px`。
* **圆角 (Border Radius)**：
* 大卡片/弹窗：`16px`
* 小标签/按钮：`8px`
* 录音大按钮：`100px` (正圆形)

## 三、 Cursor 开发技术栈与组件推荐

考虑到 Cursor 对前端框架的理解深度，以及快速打包 Android APK 的需求，**强烈推荐使用 React Native (基于 Expo 框架)** 或 **Flutter**。

这里为您提供最适合让 Cursor 快速出结果的组件库清单：

### 方案 A：React Native + Expo (推荐，Cursor 对 React 的理解最深)

由于 Cursor 是基于大型语言模型（极度擅长 TypeScript 和 React），用这套方案开发效率最高。

* **核心框架**：`Expo` (SDK 50+，方便直接打包 APK，免去配 Android Studio 环境的痛苦)。
* **UI 组件库**：**`Tamagui`** 或 **`React Native Paper`**。推荐 `React Native Paper`（遵循 Material Design，自带卡片、按钮、输入框，极易定制颜色）。
* **路由导航**：`Expo Router` (基于文件系统的路由，Cursor 写起来最不易出错)。
* **音频处理/录音**：`expo-av` (原生支持录音和播放，API 成熟)。
* **声波动效**：使用 `react-native-reanimated` 配合音频分贝数据自己画一组动态柱状体，或者使用第三方库 `react-native-audio-waveform`。
* **本地数据库**：`@nozbe/watermelondb` 或简单的 `AsyncStorage` (第一版 MVP 推荐 AsyncStorage + Zustand 持久化即可，最简单)。

### 方案 B：Flutter (适合追求极致流畅动效和原生性能)

如果您希望打包出的 APK 体积更小、声波动画极其丝滑，选 Flutter。

* **核心框架**：`Flutter` (Dart 语言)。
* **UI 组件**：直接使用 Flutter 强大的内建组件 `Material 3`，配合自定义 `ThemeData` 即可完美还原设计。完全不需要第三方 UI 库。
* **状态管理**：`Riverpod` (目前 Flutter 社区最推崇，结构清晰)。
* **音频处理**：`record` (用于高品质录音，支持流式抛出振幅数据) + `audioplayers` (用于播放)。
* **声波动效**：`audio_waveforms` (Flutter 现成的高级波形图组件，完美契合您的需求)。
* **本地数据库**：`Isar` (极其快速的 NoSQL 本地数据库，特别适合存大量的转写文本和长列表)。
